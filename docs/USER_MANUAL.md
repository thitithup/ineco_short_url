# Short URL Generator - คู่มือการใช้งานระบบ (User Manual) 📖

คู่มือสำหรับผู้ใช้งานทั่วไป ผู้ดูแลธุรกิจ (Business Operations) และผู้ดูแลระบบ

---

## 1. บทนำและกลุ่มผู้ใช้งาน (Introduction & Roles)

ระบบ **Short URL Generator** ช่วยแปลงลิงก์ที่มีขนาดยาวหรือซับซ้อนให้กลายเป็นลิงก์สั้นที่จดจำง่าย เหมาะสำหรับการนำไปแชร์บนโซเชียลมีเดีย สื่อสิ่งพิมพ์ หรือส่งทาง SMS

### บทบาทในระบบ:
1. **ผู้สร้างลิงก์ (Creator / Operations Staff):** ถือสิทธิ์ API Key สำหรับสร้างลิงก์และตรวจดูรายงานสถิติ
2. **ผู้เข้าชมทั่วไป (Visitors / Public Users):** ผู้คลิกลิงก์ย่อเพื่อส่งต่อไปยังเว็บไซต์ปลายทาง

---

## 2. ขั้นตอนการใช้งานฟังก์ชันหลัก (Step-by-Step Workflows)

### ขั้นตอนที่ 1: การขอสิทธิ์เข้าใช้งาน (API Key)
ก่อนเริ่มต้นสร้างลิงก์ ให้ขอรับกุญแจ `X-API-Key` จากผู้ดูแลระบบ (ค่ามาตรฐานเริ่มต้นสำหรับการทดสอบคือ: `ineco-secret-key-12345`)

---

### ขั้นตอนที่ 2: วิธีการสร้างลิงก์ย่อใหม่
สามารถสร้างผ่าน Swagger Interactive UI ที่หน้าเว็บ `http://localhost:8000/docs` หรือผ่านโปรแกรม Postman/cURL:

1. ใส่ URL ปลายทางที่คุณต้องการ เช่น `https://ineco.tech/promotions/summer-sale-2026`
2. *(ทางเลือก)* กำหนดอายุการใช้งานในหน่วยชั่วโมง เช่น `48` (หากไม่ระบุ ลิงก์จะไม่มีวันหมดอายุ)
3. กดส่งข้อมูล ระบบจะคืนค่ารหัสย่อ 6 หลัก เช่น `s8F2aX`
4. ลิงก์ย่อที่พร้อมใช้งานของคุณคือ: `http://localhost:8000/s8F2aX`

> [!TIP]
> ลิงก์ที่สร้างขึ้นมาจะคงอยู่ถาวร เว้นแต่จะมีการระบุวันหมดอายุไว้ล่วงหน้า

---

### ขั้นตอนที่ 3: การแชร์และส่งต่อผู้เข้าชม (Redirection)
- เมื่อลูกค้านำลิงก์ `http://localhost:8000/s8F2aX` ไปเปิดบน Browser ใดๆ ระบบจะทำการส่งต่อไปยังเว็บไซต์จริงทันทีอย่างรวดเร็ว (ความเร็วเฉลี่ยต่ำกว่า 5ms)
- ทุกครั้งที่เปิด ระบบจะนับยอดการคลิกสะสมเพิ่มขึ้น 1 ครั้งอัตโนมัติ

---

### ขั้นตอนที่ 4: การตรวจสอบผลลัพธ์และสถิติ (Analytics Report)
เมื่อต้องการดูว่าแคมเปญของคุณมีผู้คลิกมากน้อยเพียงใด:
1. ส่งคำขอไปที่ `GET /api/v1/analytics/{short_code}` พร้อมแนบ `X-API-Key`
2. ข้อมูลที่ได้รับจะประกอบด้วย:
   - **ยอดคลิกทั้งหมด (Total Clicks)**
   - **สถานะการหมดอายุ (Is Expired)**
   - **ประวัติการคลิกล่าสุด:** วันเวลา, ประเภทอุปกรณ์ (มือถือ/คอมพิวเตอร์), และเว็บไซต์ต้นทาง

---

### ขั้นตอนที่ 5: การขอรับภาพ QR Code สำหรับพิมพ์หรือแชร์
หากต้องการนำ QR Code ไปพิมพ์ลงบนโบรชัวร์ บนนามบัตร หรือแปะลงในสื่อโซเชียลมีเดีย:
1. เปิดเบราว์เซอร์ไปที่: `http://localhost:8000/api/v1/qrcode/{short_code}` (เช่น `http://localhost:8000/api/v1/qrcode/s8F2aX`)
2. เบราว์เซอร์จะแสดงภาพ **QR Code (PNG)** ความคมชัดสูงทันที
3. คุณสามารถคลิกขวาแล้วกด "Save image as..." เพื่อนำภาพไปใช้งานได้เลย
4. ผู้ที่สแกนภาพ QR Code นี้ด้วยมือถือ จะถูกส่งต่อไปยังเว็บไซต์ปลายทางทันทีเช่นเดียวกัน

## 3. คำถามที่พบบ่อยและวิธีแก้ปัญหา (FAQ & Troubleshooting)

### Q1: ทำไมเปิดลิงก์แล้วขึ้นข้อความแจ้งว่า "URL_EXPIRED" (HTTP 410)?
* **สาเหตุ:** ลิงก์ดังกล่าวเกินกำหนดอายุการใช้งานที่ผู้สร้างตั้งไว้
* **วิธีแก้:** ต้องสร้างลิงก์ย่อใหม่เนื่องจากลิงก์เดิมถูกปิดการใช้งานอย่างถาวรแล้ว

### Q2: เรียกใช้งาน API แล้วได้คำตอบว่า "MISSING_API_KEY" หรือ "INVALID_API_KEY"?
* **สาเหตุ:** ลืมใส่ Header ชื่อ `X-API-Key` หรือกรอกรหัสไม่ถูกต้อง
* **วิธีแก้:** ตรวจสอบ Header ในโปรแกรมที่ส่งว่าสะกดถูกต้องหรือไม่ (`X-API-Key`)

### Q3: รหัสย่อ 6 หลักมีโอกาสซ้ำกันหรือไม่?
* **คำตอบ:** ระบบใช้ชุดตัวอักษร 62 ตัว (Base62) ความยาว 6 หลัก ซึ่งรองรับการผสมรหัสได้มากกว่า **56,800 ล้านรหัส** และมีระบบตรวจสอบการชนซ้ำอัตโนมัติ จึงมั่นใจได้ว่าจะไม่เกิดรหัสชนกัน
